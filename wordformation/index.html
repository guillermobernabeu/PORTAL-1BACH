Las 3 estructuras

Primero decide cuál de las tres es. El español te lo dice.

used to + infinitivo

Solía: algo del pasado que ya no pasa.

I used to play football.

be used to + -ing

Estar acostumbrado: un estado. Cambia de tiempo el verbo be.

They are used to working under pressure.

get used to + -ing

Acostumbrarse: un proceso. Cambia de tiempo el verbo get.

I'm getting used to the cold weather.

Truco: me, te, se, nos, os = get

Si en español el verbo lleva me / te / se / nos / os (me acostumbro, se está acostumbrando), es get used to. Si dice estoy / está acostumbrado, es be used to.

Used o use: la -d

AfirmativaI used to play.
Negativa con didn'tI didn't use to play.
Pregunta con didDid you use to play?
be / get used toI'm used to it · get used to it (siempre con -d)

Igual que did you play, no did you played.

Después de be / get used to: -ing

Ahí to es una preposición, así que detrás va -ing o un sustantivo, nunca el infinitivo.

used to drive → used to driving
used to study → used to studying
used to the cold (sustantivo)

Paso 2

Luego mira el sentido: ¿es negativo?

Un prefijo cambia el significado, pero no el tipo de palabra: happy y unhappy son los dos adjetivos. Si la frase habla de algo malo, contrario o que falta, prueba con un prefijo negativo.

Paso 3

Cuidado: a veces hay dos o tres cambios a la vez

Un prefijo y un sufijo juntos son muy típicos de examen. Comprueba siempre las dos cosas: el tipo de palabra y el sentido.

bear → unbearable
fortune → unfortunately
employ → unemployment
care → carefully

-ed o -ing

-ed es cómo se siente una persona: I was bored. -ing es lo que provoca ese sentimiento: The film was boring.

Pista rápida: si es una cosa (una película, una historia, un partido), casi siempre va con -ing. Las historias no sienten, provocan.

Cambios de ortografía

La -e final se pierde ante vocalarrive → arrival, fame → famous
La -e se queda ante consonanteuse → useful, hope → hopeless
-y pasa a -ihappy → happiness, easy → easily
Consonante doblerob → robbery, red → reddish
-le pasa a -lyterrible → terribly

Sustantivos irregulares

No llevan los sufijos de siempre. Apréndelos de memoria:

No calques del español

Estas palabras no existen en inglés, aunque suenen bien:

modificate → modify
desinstall → uninstall
ilegal → illegal
desagree → disagree
