# Portal 1.º Bachillerato

Portal de estudio para la clase. Se entra una vez con Google y se tiene acceso a todos los proyectos.

- `index.html`: portada (entrar con Google, proyectos y quién está conectado).
- `shared/`: conexión a Firebase, estilos y la lista de proyectos (`proyectos.js`).
- `vocabulary/`: Vocabulary 1st Term (definición ↔ palabra, lista compartida).

Para añadir un proyecto: crear su carpeta y añadirlo a `shared/proyectos.js`.
